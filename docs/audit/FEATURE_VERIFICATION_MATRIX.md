---

## Allowed Audit Status Definitions

- **VERIFIED WORKING**: Confirmed through runtime API requests or test suites with verified input/output evidence.
- **IMPLEMENTED BUT UNVERIFIED**: Code exists and compiles, but lacks live end-to-end automated verification or integration tests.
- **PARTIALLY IMPLEMENTED**: Functional skeleton exists, but critical logic paths, error cases, or data persistence are missing.
- **VISUAL ONLY**: UI elements render on screen, but actions trigger no backend change, mock data is hardcoded, or form data is dropped.
- **BROKEN**: Code exists but fails at runtime with exceptions, build failures, or fatal errors.
- **MISSING**: Required product capability has not been implemented in code.
- **BLOCKED**: Implementation cannot function due to missing external credentials, unapplied database migrations, or infrastructure failures.
